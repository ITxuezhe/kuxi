Local first

密码和 Key，都不该离开你的电脑

数据库客户端最怕两件事：连接密码泄漏、AI 把整张表传出去。库犀从架构上把这两条卡住。

密码由系统加密落盘

连接密码用 Electron safeStorage（macOS 钥匙串 / Windows DPAPI）加密，明文不下发到界面进程；导出的连接配置里也不含密文。

AI Key 只在主进程用

模型请求由主进程发出，渲染层拿不到 Key。你可以用自己的 Key，也可以指向本地 Ollama，模型完全离线。

危险语句先拦一下

DROP、整表 DELETE、TRUNCATE 这类语句执行前会二次确认，把生成的 SQL 原样展示，改完再跑。

驱动跑在主进程

数据库驱动不暴露给网页层，界面只通过 IPC 调用。查询在主进程执行，结果按需回传，减少中间环节。

FAQ

几个常见问题

它会把我的数据传到服务器吗？
查询本身在你的电脑上执行，结果也留在本机。只有当你使用 AI 提问时，会把表名、字段名和少量样例值作为上下文发给模型服务商；模型用本地 Ollama 时可以完全不出网。连接密码与 API Key 都不会离开本机。
支持哪些数据库？
v0.1.0 支持 SQLite、MySQL、PostgreSQL。先把这三个做深，后续按需求扩展。计划中的有 SQL Server、MariaDB、ClickHouse。
必须自己准备 AI Key 吗？
不用 AI 也能当普通客户端使用：连接、SQL 编辑器、结果导出、表设计器都能用。要用 AI 就填一个自己的 Key（DeepSeek / OpenAI / 任意 OpenAI 兼容接口），或指向本地 Ollama，费用直接由服务商按量结算。
为什么包这么大？
Electron 运行时本身约 90 MB。换来的是跨平台一致的原生窗口、成熟的自动更新和加密存储。竞品里有更轻的方案，代价通常是数据源广度或中文体验。
能商用吗？
核心以 AGPL-3.0 开源，可以自由使用、修改、自建分发。若要闭源集成到商业产品里，需要单独获取商业授权。
