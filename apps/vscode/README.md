# 库犀 Kuxi for VS Code

在 VS Code 里连接 SQLite / MySQL / PostgreSQL：侧边栏浏览库表、点表看数据、选中 SQL 右键执行。连接信息与查询结果都只留在本机。

## 新建连接

命令面板运行「库犀: 新建连接」，或点侧边栏空态里的「新建连接」：

- **SQLite**：填文件路径（可「浏览…」选 `.db/.sqlite/.sqlite3/.db3`），或 `:memory:`
- **MySQL / PostgreSQL**：主机、端口、用户名、密码、数据库，可选 SSL
- **SSH 隧道**：勾选后填跳板机、端口、SSH 用户，可选密码或私钥（+ 私钥口令），数据库连接会经跳板机转发
- **分组**：给连接起个组名，侧边栏会按组归类
- **保存范围**：仅当前工作区（默认）或全局（所有窗口可见）
- 「测试连接」先验证凭据再保存；连接名称留空则自动生成

密码与 SSH 口令存进系统钥匙串（VS Code SecretStorage），扩展配置里只留「是否已保存」标记，不写明文。

## 侧边栏

- 已保存连接按「分组 → 连接 → 表 → 列」展开，未分组连接排在最前
- 未连接的保存项点一下即建连；已连接的按活动连接展开表
- 右键已保存连接可「连接」「断开」「删除」；临时会话连接在「本次会话」组
- 活动栏顶部有新建连接、打开文件、刷新三个按钮

## 其他入口

- 资源管理器右键 `.db/.sqlite/.sqlite3/.db3` → 「库犀: 打开数据库文件」
- 编辑器选中 SQL → 右键「库犀: 执行选中 SQL」

## 命令

| 命令 | 说明 |
| --- | --- |
| 库犀: 新建连接 | 完整连接表单（SQLite / MySQL / PostgreSQL + SSH 隧道） |
| 库犀: 快速连接 SQLite | 直接输入文件路径 |
| 库犀: 打开数据库文件 | 文件选择器打开 SQLite |
| 库犀: 连接已保存连接 | 用已保存配置建连（含 SSH） |
| 库犀: 删除已保存连接 | 删除配置与钥匙串中的口令 |
| 库犀: 查看表数据 | 选表后执行 `SELECT * ... LIMIT 200` |
| 库犀: 执行只读查询 | 单条 SELECT，最多返回 200 行 |
| 库犀: 执行选中 SQL | 执行编辑器中选中的 SQL |
| 库犀: 查询结果跑管线（按列去重） | 选一个字段对结果去重 |
| 库犀: 设为当前连接 / 刷新 / 断开连接 / 列出表 | 连接管理 |

## 结果表格

查询结果在侧边 Webview 中展示：

- 点表头排序（数字按数值、文本按中文排序）
- 「复制 CSV」到剪贴板
- 「导出 CSV…」保存到文件（带 BOM，Excel 打开中文不乱码）
- 可展开查看执行的 SQL

## 说明

- 只读：INSERT / UPDATE / DELETE / DDL 等写操作会被引擎直接拒绝。
- 连接配置保存在 VS Code 的全局/工作区存储中，密码与 SSH 口令保存在系统钥匙串；卸载扩展会一并清除。
- 查询同步执行，大表请自行加 `LIMIT`。

## 环境要求

- VS Code 1.103 及以上（扩展依赖内置 `node:sqlite`，需要 Node 22.13+）。
